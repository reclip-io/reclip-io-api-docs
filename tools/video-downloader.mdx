Download videos from supported social platforms with a paid plan.

<Info>Public beta. Read the live tool catalog before choosing models, voices, presets, or source formats.</Info>

Submit `POST /jobs` with `tool: "video_downloader"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Available on **starter** plans or with sufficient API credits. API work can use API-only promotional credits or shared workspace credits, including purchased credits without a subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `source_url` | Yes | string | See the full schema below. |
| `platform` | Yes | string | Allowed: `youtube`, `tiktok`, `instagram` |
| `file_name` | Yes | string | See the full schema below. |
| `format_id` | Yes | union | See the full schema below. |
| `format_height` | No | union | See the full schema below. |
| `format_size_bytes` | No | union | See the full schema below. |
| `maximum_download_bytes` | Yes | integer | See the full schema below. |
| `has_audio` | Yes | union | See the full schema below. |
| `source_title` | Yes | union | See the full schema below. |
| `source_creator` | Yes | union | See the full schema below. |
| `source_thumbnail_url` | Yes | union | See the full schema below. |
| `source_duration_seconds` | Yes | union | See the full schema below. |

Inspect `GET /tools/video_downloader/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

This operation does not advertise an upload policy.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
