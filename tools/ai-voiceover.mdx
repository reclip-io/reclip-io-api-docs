Turn text into a natural AI voiceover.

<Info>Beta implementation. Live provider acceptance remains a release gate; this page does not claim production availability.</Info>

Submit `POST /jobs` with `tool: "ai_voiceover"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Required plan tier: **free**. API access additionally requires an active paid subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `script` | Yes | string | See the full schema below. |
| `voice_id` | Yes | string | See the full schema below. |
| `model_id` | Yes | string | See the full schema below. |
| `public_owner_id` | Yes | union | See the full schema below. |
| `voice_source` | Yes | string | Allowed: `library`, `custom` |
| `stability` | Yes | number | See the full schema below. |
| `similarity` | Yes | number | See the full schema below. |
| `speed` | Yes | number | See the full schema below. |
| `use_speaker_boost` | Yes | boolean | See the full schema below. |

Inspect `GET /tools/ai_voiceover/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

This operation does not advertise an upload policy.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
