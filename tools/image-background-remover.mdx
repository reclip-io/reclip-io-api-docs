Remove or replace an image background with selectable AI models.

<Info>Beta implementation. Live provider acceptance remains a release gate; this page does not claim production availability.</Info>

Submit `POST /jobs` with `tool: "image_background_remover"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Required plan tier: **starter**. API access additionally requires an active paid subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `asset_id` | Yes | string | See the full schema below. |
| `file_name` | Yes | string | See the full schema below. |
| `model` | Yes | string | Allowed: `recraft`, `flux-kontext-pro`, `flux-kontext-max` |

## Complete input schema

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "asset_id": {
      "type": "string",
      "format": "uuid",
      "pattern": "^([0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[1-8][0-9a-fA-F]{3}-[89abAB][0-9a-fA-F]{3}-[0-9a-fA-F]{12}|00000000-0000-0000-0000-000000000000|ffffffff-ffff-ffff-ffff-ffffffffffff)$"
    },
    "file_name": {
      "type": "string",
      "minLength": 1,
      "maxLength": 255
    },
    "model": {
      "type": "string",
      "enum": [
        "recraft",
        "flux-kontext-pro",
        "flux-kontext-max"
      ]
    }
  },
  "required": [
    "asset_id",
    "file_name",
    "model"
  ],
  "additionalProperties": false
}
```

Inspect `GET /tools/image_background_remover/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

Uploads: up to 5242880 bytes before deployment-specific caps; MIME types: image/jpeg, image/png, image/webp.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
