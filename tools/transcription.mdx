Transcribe uploaded video with optional timestamps.

<Info>Beta implementation. Live provider acceptance remains a release gate; this page does not claim production availability.</Info>

Submit `POST /jobs` with `tool: "transcription"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Required plan tier: **free**. API access additionally requires an active paid subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `asset_id` | Yes | string | See the full schema below. |
| `file_name` | Yes | string | See the full schema below. |
| `duration_seconds` | Yes | number | See the full schema below. |
| `include_timestamps` | Yes | boolean | See the full schema below. |

## Complete input schema

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "asset_id": {
      "type": "string",
      "format": "uuid",
      "pattern": "^([0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[1-8][0-9a-fA-F]{3}-[89abAB][0-9a-fA-F]{3}-[0-9a-fA-F]{12}|00000000-0000-0000-0000-000000000000|ffffffff-ffff-ffff-ffff-ffffffffffff)$"
    },
    "file_name": {
      "type": "string",
      "minLength": 1,
      "maxLength": 255
    },
    "duration_seconds": {
      "type": "number",
      "exclusiveMinimum": 0,
      "maximum": 5400
    },
    "include_timestamps": {
      "type": "boolean"
    }
  },
  "required": [
    "asset_id",
    "file_name",
    "duration_seconds",
    "include_timestamps"
  ],
  "additionalProperties": false
}
```

Inspect `GET /tools/transcription/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

Uploads: up to 524288000 bytes before deployment-specific caps; MIME types: video/mp4, video/quicktime, video/webm, video/x-msvideo, video/x-matroska, video/x-ms-wmv.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
