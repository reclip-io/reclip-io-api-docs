Generate videos from text prompts or reference images.

<Info>Public beta. Read the live tool catalog before choosing models, voices, presets, or source formats.</Info>

Submit `POST /jobs` with `tool: "ai_video_generator"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Required plan tier: **starter**. API access additionally requires an active paid subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `prompt` | Yes | string | See the full schema below. |
| `model` | Yes | string | Allowed: `veo3_fast`, `grok_imagine`, `google_omni`, `kling`, `seedance2`, `seedance2_fast`, `seedance2_mini` |
| `format` | Yes | string | Allowed: `9:16`, `16:9` |
| `duration_seconds` | Yes | integer | See the full schema below. |
| `variants` | Yes | number | See the full schema below. |
| `reference_kind` | Yes | string | Allowed: `generic`, `frames` |
| `grok_mode` | Yes | string | Allowed: `normal`, `fun` |
| `grok_resolution` | Yes | string | Allowed: `480p`, `720p` |
| `seedance_resolution` | Yes | string | Allowed: `480p`, `720p`, `1080p` |
| `omni_resolution` | Yes | string | Allowed: `720p`, `1080p`, `4K` |
| `audio_enabled` | Yes | boolean | See the full schema below. |
| `input_asset_ids` | Yes | array | See the full schema below. |

Inspect `GET /tools/ai_video_generator/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

Uploads: up to 10485760 bytes before deployment-specific caps; MIME types: image/jpeg, image/png, image/webp.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
