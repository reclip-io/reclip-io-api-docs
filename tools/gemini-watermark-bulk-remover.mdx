Remove supported visible Gemini image watermarks on the server. Results identify applied, needs_review, or unsupported_watermark_style for each image.

<Info>Public beta. Read the live tool catalog before choosing models, voices, presets, or source formats.</Info>

Submit `POST /jobs` with `tool: "gemini_watermark_bulk_remover"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Required plan tier: **free**. API access additionally requires an active paid subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `input_asset_ids` | Yes | array | See the full schema below. |

Inspect `GET /tools/gemini_watermark_bulk_remover/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

Uploads: up to 10485760 bytes before deployment-specific caps; MIME types: image/jpeg, image/png, image/webp.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
