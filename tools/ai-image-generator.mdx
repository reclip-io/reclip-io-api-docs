Generate images from prompts with selectable AI models.

<Info>Public beta. Read the live tool catalog before choosing models, voices, presets, or source formats.</Info>

Submit `POST /jobs` with `tool: "ai_image_generator"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Required plan tier: **starter**. API access additionally requires an active paid subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `input_asset_ids` | Yes | array | See the full schema below. |
| `prompt` | Yes | string | See the full schema below. |
| `model` | Yes | string | Allowed: `nano-banana-2`, `nano-banana-pro`, `gpt-image-2` |
| `aspect_ratio` | Yes | string | Allowed: `1:1`, `9:16`, `16:9` |

## Complete input schema

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "input_asset_ids": {
      "maxItems": 3,
      "type": "array",
      "items": {
        "type": "string",
        "format": "uuid",
        "pattern": "^([0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[1-8][0-9a-fA-F]{3}-[89abAB][0-9a-fA-F]{3}-[0-9a-fA-F]{12}|00000000-0000-0000-0000-000000000000|ffffffff-ffff-ffff-ffff-ffffffffffff)$"
      }
    },
    "prompt": {
      "type": "string",
      "minLength": 1,
      "maxLength": 4000
    },
    "model": {
      "type": "string",
      "enum": [
        "nano-banana-2",
        "nano-banana-pro",
        "gpt-image-2"
      ]
    },
    "aspect_ratio": {
      "type": "string",
      "enum": [
        "1:1",
        "9:16",
        "16:9"
      ]
    }
  },
  "required": [
    "input_asset_ids",
    "prompt",
    "model",
    "aspect_ratio"
  ],
  "additionalProperties": false
}
```

Inspect `GET /tools/ai_image_generator/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

Uploads: up to 10485760 bytes before deployment-specific caps; MIME types: image/jpeg, image/png, image/webp.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
