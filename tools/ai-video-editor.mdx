Transform an existing video with a plain-language editing prompt.

<Info>Public beta. Read the live tool catalog before choosing models, voices, presets, or source formats.</Info>

Submit `POST /jobs` with `tool: "ai_video_editor"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Required plan tier: **starter**. API access additionally requires an active paid subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `asset_id` | Yes | string | See the full schema below. |
| `prompt` | Yes | string | See the full schema below. |
| `model` | Yes | string | Allowed: `wan/2-7-videoedit`, `happyhorse/video-edit`, `runway/aleph`, `gemini-omni-video` |
| `format` | Yes | string | Allowed: `9:16`, `16:9` |
| `duration_seconds` | Yes | integer | See the full schema below. |
| `resolution` | Yes | string | Allowed: `720p`, `1080p`, `4K` |
| `source_duration_seconds` | Yes | number | See the full schema below. |

Inspect `GET /tools/ai_video_editor/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

Uploads: up to 104857600 bytes before deployment-specific caps; MIME types: video/mp4, video/quicktime.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
