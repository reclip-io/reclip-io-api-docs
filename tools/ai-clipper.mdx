Find and render the strongest clips from long videos.

<Info>Public beta. Read the live tool catalog before choosing models, voices, presets, or source formats.</Info>

Submit `POST /jobs` with `tool: "ai_clipper"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Required plan tier: **free**. API access additionally requires an active paid subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `asset_id` | No | string | See the full schema below. |
| `source_url` | No | string | See the full schema below. |
| `options` | Yes | object | See the full schema below. |

Inspect `GET /tools/ai_clipper/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

Uploads: up to 2147483648 bytes before deployment-specific caps; MIME types: video/mp4, video/quicktime, video/webm.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
