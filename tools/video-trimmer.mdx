Trim a precise section from a video.

<Info>Beta implementation. Live provider acceptance remains a release gate; this page does not claim production availability.</Info>

Submit `POST /jobs` with `tool: "video_trimmer"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Required plan tier: **free**. API access additionally requires an active paid subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `asset_id` | Yes | string | See the full schema below. |
| `file_name` | Yes | string | See the full schema below. |
| `start_time` | Yes | number | See the full schema below. |
| `end_time` | Yes | number | See the full schema below. |

## Complete input schema

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "asset_id": {
      "type": "string",
      "format": "uuid",
      "pattern": "^([0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[1-8][0-9a-fA-F]{3}-[89abAB][0-9a-fA-F]{3}-[0-9a-fA-F]{12}|00000000-0000-0000-0000-000000000000|ffffffff-ffff-ffff-ffff-ffffffffffff)$"
    },
    "file_name": {
      "type": "string",
      "minLength": 1,
      "maxLength": 255
    },
    "start_time": {
      "type": "number",
      "minimum": 0
    },
    "end_time": {
      "type": "number",
      "exclusiveMinimum": 0
    }
  },
  "required": [
    "asset_id",
    "file_name",
    "start_time",
    "end_time"
  ],
  "additionalProperties": false
}
```

Inspect `GET /tools/video_trimmer/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

Uploads: up to 262144000 bytes before deployment-specific caps; MIME types: video/mp4, video/quicktime, video/webm, video/x-msvideo, video/x-matroska, video/x-ms-wmv.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
