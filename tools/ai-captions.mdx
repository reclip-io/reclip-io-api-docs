Add stylish captions to videos and translate subtitles into another language.

<Info>Public beta. Read the live tool catalog before choosing models, voices, presets, or source formats.</Info>

Submit `POST /jobs` with `tool: "ai_captions"`. Put these tool fields inside `input`, except nested `options`, which may be supplied at the request top level. Both forms are accepted, but do not supply options twice.

Available on **free** plans or with sufficient API credits. API work can use API-only promotional credits or shared workspace credits, including purchased credits without a subscription.

| Input field | Required | Type | Details |
|---|---|---|---|
| `asset_id` | No | string | See the full schema below. |
| `source_url` | No | string | See the full schema below. |
| `duration_seconds` | Yes | number | See the full schema below. |
| `start_seconds` | Yes | number | See the full schema below. |
| `end_seconds` | No | number | See the full schema below. |
| `options` | Yes | object | See the full schema below. |

Inspect `GET /tools/ai_captions/catalog` for supported choices. Runtime checks also validate cross-field rules, source ownership and tool-specific URL restrictions. Quote the exact request before submission.

Uploads: up to 4294967296 bytes before deployment-specific caps; MIME types: video/mp4, video/quicktime, video/webm.

Results are returned through `GET /jobs/{id}`; output assets can be passed to the next tool. [Job lifecycle](/concepts/jobs).
