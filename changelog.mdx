## 1.0.0-beta.1

Initial implementation reference: scoped keys, shared workspace credits, uploads, jobs, projects, clip editing/export, tool catalog, OpenAPI and an executable Reclip skill.

Database integration coverage verifies durable admission; it does not certify real provider output for every tool. Production deployment, migration application and provider acceptance are separate release gates. Breaking contract changes require a new major API version; additive fields may be introduced in v1.
